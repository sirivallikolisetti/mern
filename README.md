# 🏥 Healthcare Appointment Scheduling System

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) web application for booking and managing healthcare appointments with secure user authentication.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Password Encryption using bcrypt
- Book & Manage Appointments
- Responsive User Interface
- MongoDB Database Integration

## 🛠️ Tech Stack

**Frontend**
- React.js
- React Router DOM
- Axios
- HTML, CSS, JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose

**Authentication**
- JWT
- bcrypt

## ⚙️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/Healthcare-Appointment-System.git
cd Healthcare-Appointment-System
```

### Install Frontend

```bash
cd front
npm install
```

### Install Backend

```bash
cd ../back
npm install
```

## ▶️ Run the Project

### Start Backend

```bash
cd back
npm start
```

### Start Frontend

```bash
cd front
npm start
```

## 🔑 Environment Variables

Create a `.env` file inside the **back** folder.

```env
PORT=5000
MONGO_URI=Your_MongoDB_URI
JWT_SECRET=Your_JWT_Secret
```
